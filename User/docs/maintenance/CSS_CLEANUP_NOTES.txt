PGENRO IMS - CSS CONSOLIDATION
Date: 2026-09-14

CSS was reorganized into one stylesheet per major interface category.

Active CSS files:
- User/user.css                 Authenticated user modules + Settings
- User/auth.css                 Login + Account Request
- admin/admin.css               All administrator modules
- VisitorsLog/visitorslog.css   Public visitor registration
- supabase-test.css             Supabase diagnostic page

What changed:
- Removed obsolete/unreferenced admin-modern.css, admin-ui.css, visitors-admin-enhanced.css after merging required rules.
- Merged each module's required CSS into the category stylesheet.
- Scoped module rules with data-css-scope so styles from one page do not override another page.
- Removed broken references to the missing shared/*.css files.
- Fixed CSS filename/casing problems by using one stable stylesheet URL per category.
- Preserved shared user/admin/global visual rules inside the appropriate consolidated file.

JavaScript, Supabase logic, database SQL, and application CRUD logic were not intentionally changed by this CSS cleanup.
