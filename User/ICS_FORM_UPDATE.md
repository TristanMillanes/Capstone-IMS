# Public ICS form

The standalone `ics-form.html`, `ics-form.css`, and `ics-form.js` are preserved from the upload for the existing anonymous public submission workflow. They use the existing `submit_public_ics` service. Its availability and permissions belong to the parent project.

The authenticated `ics.html` workspace is now a viewer: its submission button, submission dialog, and save handler were removed. Use the shared registry to view property records, read attached files, or print slips.

Install this package by replacing the **User** folder only. Keep the existing parent folders and configuration. See **USER_UI_UPDATE.md** for the current installation instructions and **VERIFICATION.md** for this update's checks.
