# PGENRO IMS — Consolidated Cleanup (2026-09-13)

## What was cleaned
- Standardized application HTML URLs to lowercase for Linux/Apache/Nginx hosting.
- Removed the redundant `shared/repaired-ui.js` layer; existing shared workspace/global scripts already provide its behavior.
- Removed orphaned legacy UI CSS/JS files that were no longer linked by any page.
- Removed repeated shared CSS embedded in every module file. Module CSS is now
  page-specific, while admin, user, public, and diagnostic rules are cached once
  from `shared/`.
- Reduced the total CSS payload from 3,458,097 bytes to 943,964 bytes (72.7%).
- Fixed internal navigation references affected by filename casing.
- Added a root `index.html` that opens the personnel login.
- Hardened the OCR endpoint against unsafe filenames, request-size abuse, temporary-file collisions, and debug-mode exposure.
- Added `User/requirements-ocr.txt` for repeatable OCR backend setup.
